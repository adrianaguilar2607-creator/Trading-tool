# Mis Visitas — Planificador para iPhone

Aplicación web PWA que funciona sin conexión tras una primera carga. Agrupa ascensores por edificio y ayuda a reorganizar las visitas diarias.

**Privacidad:** el inventario de clientes, direcciones y números RAE **no se incluye en este repositorio público**. Debe importarse desde el teléfono mediante un archivo JSON privado. Los cambios se guardan localmente y pueden exportarse.

**Puesta en marcha:** en GitHub Settings > Pages, elegir Deploy from a branch, main, /(root) y guardar. Abrir la URL https://adrianaguilar2607-creator.github.io/Trading-tool/ desde Safari. Añadir a pantalla de inicio e importar el inventario privado.

**Limitación:** utiliza distancias geográficas aproximadas, no rutas viales ni tráfico en tiempo real; confirmar horarios y entradas antes de visitar.

**Respaldo:** el contenido anterior de Trading-tool está en la rama `respaldo-trading-tool-2026-10-22`.
